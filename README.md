# Blossom & Barley – landingspagina

Campagne **Bloom Together – Summer in every sip.**
Statische website (HTML, CSS, JS), klaar voor GitHub Pages.

- `index.html` – landingspagina (hero, smaken, video, verhaal, how to brew, Bloom Club-form, footer)
- `privacy.html` – korte privacyverklaring (gelinkt in form en footer)
- `css/style.css` – merkstijl en animaties · `css/mailerlite.css` – stijl van het MailerLite-form
- `js/main.js` – navigatie, scroll-animaties, video + geluidsknop, blaadjes bij inschrijving
- `img/`, `videos/`, `fonts/` – geoptimaliseerde beelden (WebP), video (720p) en DM Serif Display / DM Sans

Fictief merk, gemaakt voor het vak Creative Automation. Beelden en copy deels gegenereerd met AI.
